# Reviewable model-quality evidence

The comparison's graders overlooked supplied instructions and the latest email,
called true company capabilities inventions, and equated unsupported explanations
with wrong task decisions. Arithmetic review did not detect this semantic defect.
The CTO needs actual discordant cases and a complete role/cost comparison, not
another uninspectable score or an instruction to resolve technical evaluation work.

Repair the offline evaluation tooling so each blinded output has its own complete
prompt, tool schema, resolved clock and final-output evidence. Keep later company
facts separately sourced and dated. Require exact quotations and explicit section
coverage, with independent dimensions for task decision, explanatory grounding,
factual truth and operational impact. A mechanical validator can prove quotation
presence and declared coverage, not reviewer comprehension or real-world truth.

Investigate the remaining claimed model differences against complete threads and
read-only company evidence. Preserve source dates, distinguish later confirmation
from information supplied to the model, and never treat an assistant-written mail
or generated memory as automatically authoritative business truth. Unknown facts
stay unknown; raw responses are not rerun or silently replaced.

Scope is local evaluation code, private evidence and public sanitized reports.
No production configuration, mailbox processing, outgoing correspondence or paid
model inference is required. Company capability keys remain private. The desired
outcome is a reproducible, reviewable comparison with explicit limitations and
concrete case evidence, plus regression coverage for the evaluation mistakes.
