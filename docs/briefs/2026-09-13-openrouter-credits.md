# OpenRouter through MrCall credits and personal keys

The operator authorizes server OpenRouter provisioning and the corresponding
Desktop model selection. The company key is supplied in the ignored deployment
secret files for test and production; personal keys will be entered by the
operator through Desktop. Existing mailbox preparation stays paused with saved
USD5 limits. The previous unvalidated economy downgrade is not evidence of quality.

Payment mode and model choice are independent. MrCall-credit calls use server
credentials and charge the authenticated business's StarChat CALLCREDIT pool.
Personal-key calls use only the active engine profile's key and do not charge
MrCall. Exact model IDs and available transports are visible, with no implicit
provider/model fallback. Existing configured role choices are preserved.

Bounded quotes reserve maximum customer debit, including markup and credit
rounding. OpenRouter usage.cost is the authoritative per-generation platform
charge, validated server-side; token prices are for preauthorization only.
Provider price caps and finite supported text/tool features constrain dispatch.
Persist request, upstream generation ID and accounting metadata for traceability;
never repeat inference/debit after uncertainty. Cost lookup may recover known
usage when a generation ID exists, but must not guess or redispatch.
